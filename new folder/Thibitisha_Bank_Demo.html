🔌 Integration Points in a Kenyan Bank
A. Login Authentication
After password validation, BEFORE OTP is sent. Checks if user's phone has been SIM-swapped.
B. Transaction Authorization
After user initiates transfer, BEFORE OTP. Checks recipient + SIM + device + location.
C. New Payee Addition
When adding a beneficiary. Verifies recipient's line legitimacy and merchant badge.
D. ATM Cardless Withdrawal
Before generating withdrawal code. Checks phone line + ATM location vs. user pattern.
E. Batch/Standing Orders
When scheduled payments execute. Async verification of account holder line status.
F. High-Value Transfers
Any transaction above bank threshold. Enhanced verification with all signals.
